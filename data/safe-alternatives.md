# ✅ 安全替代品推荐

> 过敏原食物的安全替代方案，让敏宝饮食不单调。

---

## 🥛 牛奶蛋白过敏（CMPA）替代方案

### 0-1 岁：配方奶替代

| 方案 | 适用情况 | 说明 |
|------|---------|------|
| **深度水解配方** | 轻中度 CMPA | 牛奶蛋白分解为小肽，90%以上CMPA宝宝可耐受 |
| **氨基酸配方** | 中重度 CMPA / 深度水解无效 | 完全游离氨基酸，无免疫原性 |
| **豆基配方** | 医生评估后 | 约10-15%CMPA宝宝合并大豆过敏 |
| **羊奶/马奶** | ❌ 不推荐 | 交叉过敏率>90% |

> ⚠️ 0-1岁宝宝的主要营养来源是奶，绝对不能用普通植物奶替代配方奶！植物奶仅作为1岁后的补充饮品。

### 1 岁后：饮品替代

| 替代品 | 营养特点 | 注意事项 |
|--------|---------|---------|
| 🥛 深度水解/氨基酸配方 | 营养全面，医生指导 | 建议继续用到耐受评估通过 |
| 🌾 燕麦奶 | 低过敏，口感好 | 选择无糖、无添加乳制品的纯燕麦奶 |
| 🍚 大米奶/米浆 | 低过敏，温和 | 蛋白质含量偏低，需从其他来源补充 |
| 🥥 椰奶 | 天然无乳 | 脂肪含量高，蛋白质低，注意稀释 |
| 🫘 豆浆 | 植物蛋白丰富 | 确认宝宝无大豆过敏 |

### 烘焙/烹饪中的乳制品替代

| 原食材 | 替代方案 |
|--------|---------|
| 牛奶 | 等量燕麦奶 / 大米奶 / 水 |
| 黄油 | 等量植物油（菜籽油、葵花籽油） |
| 奶油 | 椰奶油（罐装椰奶上层） |
| 奶酪 | 营养酵母（增加芝士风味） |
| 酸奶 | 无乳植物酸奶（椰奶/燕麦奶基底） |

## 🥚 鸡蛋过敏替代方案

### 烘焙中替代鸡蛋

| 用途 | 替代方案（每个鸡蛋） |
|------|---------------------|
| 粘合/膨松 | 1 汤匙亚麻籽粉 + 3 汤匙水，静置5分钟 |
| 湿润度 | 半根香蕉（压泥） |
| 膨松 | 1 茶匙泡打粉 + 1 汤匙水 + 1 汤匙油 |
| 粘合 | 2 汤匙豆腐（嫩滑型，打泥） |
| 增湿 | ¼ 杯苹果酱/南瓜泥 |

### 日常饮食替代

| 原食材 | 替代方案 |
|--------|---------|
| 鸡蛋（蛋白质） | 豆腐、豆干、肉类、鱼类 |
| 蛋黄酱 | 无蛋黄沙拉酱 / 牛油果酱 |
| 蛋糕 | 市售无蛋蛋糕 / 自制无蛋烘焙 |

## 🌾 小麦/麸质过敏替代方案

### 面粉替代

| 替代品 | 特点 | 适用 |
|--------|------|------|
| 大米粉 | 低过敏，温和 | 蛋糕、饼干、浓稠酱汁 |
| 玉米粉 | 无麸质，口感细腻 | 玉米饼、松饼 |
| 无麸质燕麦粉 | 需选GF认证 | 面包、松饼 |
| 藜麦粉 | 高蛋白 | 烘焙、粥品 |
| 荞麦粉 | 无麸质（虽名为"麦"） | 面条、煎饼 |
| 木薯粉 | 粘稠性好 | 勾芡、布丁 |

### 主食替代

| 原食材 | 替代方案 |
|--------|---------|
| 面条 | 米粉、荞麦面、无麸质面条 |
| 面包 | 无麸质面包、米饼、玉米饼 |
| 酱油 | 椰子酱油、无麸质酱油 |

## 🥜 坚果/花生过敏替代方案

### 酱料替代

| 原食材 | 替代方案 |
|--------|---------|
| 花生酱 | 葵花籽酱、南瓜籽酱 |
| 杏仁酱 | 葵花籽酱、芝麻酱（无芝麻过敏时） |
| 混合坚果酱 | 葵花籽酱 |

### 营养替代

坚果主要提供健康脂肪和维生素E，可通过以下方式补充：
- 橄榄油、菜籽油（烹饪用油）
- 牛油果（直接食用或涂抹）
-  seeds（葵花籽、南瓜籽、奇亚籽）

## 🛒 购买无敏食品小贴士

1. **看认证标识**：选择有"无乳制品"、"无麸质"、"无坚果"等认证标识的产品
2. **配料表越短越好**：成分简单的食品，隐藏过敏原的概率低
3. **新手选大牌**：大品牌的过敏原标注更规范
4. **小批量试吃**：第一次买小包装，确认安全再回购
5. **保留小票**：万一有问题方便退换
